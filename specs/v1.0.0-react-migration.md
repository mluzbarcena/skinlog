# Spec — Migración a React + Vite + TypeScript (v1.0.0)

- **Estado:** Implementada ✅
- **Fecha:** 2026-09-16
- **Versión objetivo:** 1.0.0

## Contexto

`skinlog` es una herramienta personal de seguimiento de rutina de skincare, originalmente
escrita en JavaScript vanilla (scripts clásicos bajo el namespace `window.SK`) con un build
casero (`build.mjs`) que incrustaba todo en un único `dist/index.html`. La app funcionaba y
tenía una arquitectura limpia: la lógica de negocio ya estaba aislada en funciones puras
(`config.js`, `util.js`, `logic.js`, `storage.js`) y la UI vivía aparte (`ui.js`, `app.js`)
manipulando el DOM directamente.

El objetivo fue pasar a **React + Vite + TypeScript** para mejorar el mantenimiento, sin
cambiar el comportamiento ni el modelo de datos. La persistencia sigue en **localStorage** en
esta v1.0.0 (sin backend, sin servicios externos, sin API keys).

## Decisiones

- **Lenguaje:** TypeScript.
- **Build:** Vite estándar (multi-archivo, servido por HTTP). `base: "./"` para que `dist/` sea
  portable (GitHub Pages, Netlify, subdirectorios).
- **Estilos:** Tailwind CSS v4 (plugin `@tailwindcss/vite`, config CSS-first) + sistema de
  diseño portado como tokens CSS y clases de componente en `src/index.css`.
- **PWA:** instalable (manifest + iconos + meta tags), sin dependencias extra.
- **Persistencia:** misma clave `skincareTracker:v1` → los datos existentes migran solos. Misma
  estructura de estado y misma función `migrate()`.
- **i18n (es/en):** solución custom liviana (diccionarios + hook `useI18n()`), sin dependencias.
  Idioma en `settings.language` (persistido); default autodetectado de `navigator.language`.
  Botón con icono de mundo en la Topbar + selector en Ajustes.
- **Dark mode:** clase `.dark` en `<html>` según `settings.theme` (auto/light/dark); script
  anti-flash en `index.html`.

## Arquitectura

Separación dominio ↔ vista:

- **Dominio (`src/domain/`)**: funciones puras que reciben el estado explícitamente (no leen un
  singleton). El store (`storage.ts`) es un external store agnóstico de framework
  (`subscribe` / `getSnapshot` + mutaciones) enlazado a React con **`useSyncExternalStore`**.
- **Vista (`src/components`, `src/views`)**: componentes React que leen el estado y llaman a las
  acciones del store.
- **i18n (`src/i18n/`)**: `es.ts` es la fuente de verdad y define el tipo `Dict`; `en.ts` lo
  satisface. Interpolación tipada mediante funciones en el diccionario.

## Reglas de negocio (sin cambios respecto de la versión vanilla)

- **Fases:** Fase 1 mientras `hyaluFinishedDate` sea `null`; Fase 2 para fechas
  `>= hyaluFinishedDate` (`logic.phaseForDate`).
- **Frecuencias:** `retinolB3PerWeek` (0–7), `sanaPerWeek` (1–2, tope 2 tras confirmar
  tolerancia). La app nunca las sube sola: solo sugiere (`logic.suggestNight`).
- **Retinol B3 y SANA** son tipos de noche distintos y nunca la misma noche.
- **SANA Brightening** es un paso AM opcional filtrable (`settings.brightingEnabled`).
- **Hyalu B5** se marca terminado desde la vista Fases → dispara Fase 2.
- Reglas editables centralizadas en `src/domain/config.ts`; textos en `src/i18n/`.

## Entregables

1. Código fuente completo (React + Vite + TS).
2. Estructura de archivos (README + esta spec).
3. Local: `npm install && npm run dev`.
4. Build estático: `npm run build` → `dist/`; `npm run preview`.
5. ZIP desplegable: `skinlog-dist.zip`.
6. Persistencia: clave única `skincareTracker:v1` (settings + `days` por fecha).
7. Dónde tocar reglas: `config.ts` + `logic.phaseForDate` / `logic.suggestNight`.

## Verificación

Automatizado (`npm run test`, Vitest — 13 tests):

- Fase inicial, completitud AM/PM, transición Fase 1 → 2.
- Retinol B3 y SANA como noches distintas; SANA Brightening opcional no rompe AM.
- Sugerencia de noche, advertencia por irritación, stats.
- Roundtrip export/import; día vacío no persistido.
- Smoke test: la app entera renderiza sin errores.

Manual en navegador (`npm run dev`, y en móvil con `npm run dev -- --host`):

- Datos sobreviven al refresh; cambiar de fecha no borra registros.
- Marcar Hyalu B5 activa Fase 2; SANA Brightening on/off; usabilidad móvil.
- i18n: el botón del mundo alterna es/en y persiste; primera visita autodetecta.

## Fuera de alcance (v1.0.0)

- Persistencia distinta de localStorage.
